# Searvex brand files

The approved Searvex identity, copied from the Markilo export. Outlined SVG, no font needed.

- `primary-color.svg` / `primary-reversed.svg`: horizontal lockup for light / dark backgrounds (README header).
- `symbol-color.svg` / `symbol-reversed.svg`: the mark on its own.
- `favicon.svg`: small version for 32 px and below; it switches to dark colours on its own.
- `github-social-preview.png`: 1280×640 image for the repository's social preview (set in GitHub settings).

Colours: teal `#0e4f55`, coral `#b8432d` (the caret line only), ink `#13201f`, paper `#f6f1e7`.
The HTML reports embed the lockup from `src/report/brand.ts`.
