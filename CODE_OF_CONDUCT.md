# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, welcome newcomers, and keep discussions
about the work. Harassment, discrimination and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer via GitHub (https://github.com/cihantopac).
Maintainers may remove comments, commits or contributions that violate this code and may ban repeat offenders.
